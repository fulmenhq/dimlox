# dimlox v0.1.1

`dimlox` v0.1.1 is a focused patch release that updates the gRPC dependency
selected in the module graph before the public rollout.

## Highlights

- Updates `google.golang.org/grpc` from `v1.79.2` to `v1.79.3`
- Picks up the fix for `GHSA-p77j-4mvh-x3m3`
- Leaves CLI behavior and release artifacts unchanged apart from the dependency refresh

## Why this release exists

After cutting `v0.1.0`, dependency review surfaced a critical advisory in the
previously selected gRPC version. This release moves the module graph to the
fixed version so the next public state starts from the patched dependency.

## Upgrade notes

- No command-line flags or workflows changed in this patch release
- Existing automation and release documentation from `v0.1.0` still apply
